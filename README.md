# Tsumugi（つむぎ）

思い出の動画を、1本のムービーにつむぐ。iPhoneの動画をえらんで、見どころをつなぎ、テンプレート・BGM・テロップ・撮影日を入れて1本にまとめるブラウザアプリ。

- 動画も音楽もすべて端末の中で処理します（どこにもアップロードされません）
- iPhoneのSafariで開いて「ホーム画面に追加」すると、アプリのように使えます
- 使い方は3ステップ：動画をえらぶ → 長さと形をえらぶ → テンプレをえらんで「編集スタート」
- テンプレート20種（TikTok風／ストーリー風／SNS投稿風／上下テロップなどのショート動画向けを含む）
- 自動編集のプロ技：撮影順・起承転結のカット配分・BGMの拍に合わせたカット・カット・オン・アクション・手ブレ回避・見せ場のスロー・色合わせ・J-カット・エンディング
- なめらか書き出し（WebCodecs）で最大4K保存。重すぎて進まない時は自動で画質を1段下げてやり直します

**アプリのリンク**：https://kouf0911-eng.github.io/crip-no-kouro/
